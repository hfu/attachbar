# CHANGELOG: attachbar

Format loosely follows [Keep a Changelog](https://keepachangelog.com/).
No packages are published yet (all at `0.1.0`), so everything so far is
grouped under **Unreleased**. See [DECISIONS.md](./DECISIONS.md) for the
reasoning behind these changes.

## [Unreleased]

### Added
- `AttachbarOptions.sidebarSize` to configure sidebar thickness per side
  (default `{ top: 32, bottom: 32, left: 48, right: 48 }`), replacing
  author-CSS-owned sizing.
- `docs/` build output for GitHub Pages, generated by
  `examples/mgrs-pmtiles/vite.config.ts` (relative `base`, `.nojekyll`).
  Run `npm run build:docs` to regenerate. (`68f1cf0`)
- `MgrsSourceProvider` (`examples/mgrs-pmtiles/src/mgrs-source-provider.ts`):
  a real `SpatialProvider` that reads MGRS grid labels from
  mgrs-pmtiles' live martin tileset instead of the mock degree-line
  provider. Covered by 11 unit tests. See DECISIONS.md D5. (`1cdccf4`)
- M1 monorepo skeleton: `@attachbar/core` (types + `filterAnchors`),
  `@attachbar/dom-renderer` (sidebar DOM lifecycle),
  `@attachbar/maplibre-adapter` (`createAttachbar` entry point,
  throttled event wiring), and the `examples/mgrs-pmtiles` reference
  integration with a mock MGRS provider. (`4499abf`)

### Changed
- `examples/mgrs-pmtiles/src/main.ts` now wires the map to
  `MgrsSourceProvider` against the live `mgrs-hokkaido` tileset, centers
  on Hokkaido, and adds zero-opacity "loader" layers so MapLibre fetches
  the vector tiles without drawing an in-map grid. Verified across the
  10km/1km/100m precision bands and through a resize. (`e98a6eb`)

### Fixed
- `createAttachbar(...).destroy()` now cancels any pending throttled
  `move`/`zoom`/`resize` update and unsubscribes the `load`-once
  listener, so a render scheduled just before teardown can no longer
  fire against already-removed sidebar DOM.
- Top-left corner collision: a "top" or "left" label landing in the
  rectangle shared by both sidebars is now dropped instead of rendering
  faded/clipped behind the other sidebar's background. See DECISIONS.md
  D8.
